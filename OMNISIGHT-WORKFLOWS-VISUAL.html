Common Operational Scenarios for Administrators

👤 Scenario 1: New Employee Onboarding

Complete process for adding a new employee to the system

flowchart TD A[👤 New Employee] --> B[📋 Add Employee] B --> C[🔑 Create Agent Account] C --> D[📦 Provide Installer] D --> E[💻 Employee Installs] E --> F[⏳ Pending Approval] F --> G{Admin Decision} G -->|Approve| H[✅ Device Active] G -->|Reject| I[❌ Investigate] H --> J[🔒 Grant Consent] J --> K[✅ Complete] I --> L[🔍 Troubleshoot]
  • 1 Add employee in Employees page
  • 2 Create agent account with credentials
  • 3 Provide agent installer to employee
  • 4 Approve device in Agent Approvals
  • 5 Grant necessary consent types

🖥️ Scenario 2: New Device Enrollment

How to enroll a new company-owned device

flowchart TD A[🖥️ New Device] --> B[📦 Install Agent] B --> C[🌐 Contact Server] C --> D[📋 Create Claim] D --> E[👀 Admin Reviews] E --> F{Legitimate?} F -->|Yes| G[✅ Approve] F -->|No| H[❌ Reject] G --> I[👤 Assign Employee] I --> J[🔗 Link Device] J --> K[📊 Go Online] K --> L[💓 Heartbeat] L --> M[✅ Enrolled] H --> N[📝 Record Reason]
  • 1 Install agent on new device
  • 2 Agent auto-registers with server
  • 3 Admin reviews in Agent Approvals
  • 4 Approve and assign to employee
  • 5 Verify device comes online

⚠️ Scenario 3: Device Offline Investigation

Troubleshooting offline devices

flowchart TD A[⚠️ Device Offline] --> B[📊 Check Dashboard] B --> C[🖥️ Open Device Details] C --> D[💓 Check Last Heartbeat] D --> E{When?} E -->|Recent| F[🌐 Network Issue] E -->|Older| G[💻 Agent Issue] E -->|Very Old| H[🔒 Device Off] F --> I[📞 Contact Employee] G --> J[🔍 Check Agent Service] H --> K[🔐 Check Status] I --> L[🔧 Guide Fix] J --> M{Agent Running?} M -->|Yes| N[🔄 Restart] M -->|No| O[📦 Reinstall] L --> P[✅ Back Online] N --> P O --> P
  • 1 Check device status and last heartbeat
  • 2 Determine likely cause
  • 3 Contact employee if needed
  • 4 Guide through resolution
  • 5 Verify device returns online

🚨 Scenario 6: Security Alert Response

Responding to security-related alerts

  • 3 Contain if critical
  • 4 Investigate root cause
  • 5 Document and resolve
