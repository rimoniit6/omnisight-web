👥 Actor Responsibilities Summary

What each actor is responsible for

👤 Administrator

  • Add, edit, archive employees
  • Approve and assign devices
  • Create consent policies
  • Respond to security alerts
  • Generate and distribute reports
  • Configure system settings

👥 Employee

  • Install and maintain agent
  • Grant or deny consent
  • Follow company policies
  • Report issues to admin
  • Provide information when asked

⚙️ System

  • Collect and store telemetry
  • Detect anomalies and alerts
  • Send notifications
  • Enforce access controls
  • Run automated jobs
  • Maintain audit logs

👔 Management

  • Review reports and analytics
  • Make strategic decisions
  • Approve major changes
  • Set company policies
  • Allocate resources
